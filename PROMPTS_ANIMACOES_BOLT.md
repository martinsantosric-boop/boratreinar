## 🎯 Animação 1: Bolt Celebrando Missão Concluída ⭐

### Descrição:
Animação de comemoração quando o usuário completa uma missão (ex: "Correr 3x na semana").

### Especificações:
- **Duração**: 2-3 segundos
- **Loop**: Não (animação única)
- **Uso**: Popup após completar missão

### 🤖 PROMPT PARA IA (630 caracteres):

```
Animate this character in 2.5 second celebration:

0.0s - Standing surprised, eyes wide
0.3s - Eyes bigger, mouth opens excited
0.5s - Jumps up high, both arms raised victory pose
0.8s - At peak height, lightning on head sparks bright
1.0s - Golden star particles appear around (5-8 stars)
1.5s - Lands softly, arms still up, big smile
2.0s - Arms down, thumbs up gesture
2.5s - Hold thumbs up pose

Effects: Golden sparkles floating, motion blur on jump, squash/stretch, confetti particles
Background: Solid dark blue #0D1B2A
Output: 1080x1080px, MP4, 30fps
Style: Excited celebration, motivational
```

## 🎯 Animação BÔNUS: Bolt Loop Idle (Em Espera) 🔄

### Descrição:
Animação de loop suave para quando Bolt está esperando na tela (breathing idle).

### Especificações:
- **Duração**: 2-3 segundos
- **Loop**: Sim (perfeito)
- **Uso**: Tela inicial, durante espera

### 🤖 PROMPT PARA IA (457 caracteres):

```
Animate this character in 2.5 second PERFECT LOOP (breathing idle):

0.0s - Standing, arms at sides, normal pose
0.5s - Slight squash down (inhale)
1.0s - Return to normal
1.2s - Eyes blink once (quick)
1.5s - Slight stretch up (exhale)
2.0s - Return to normal
2.5s - EXACT starting pose (must match 0.0s)

Effects: Lightning pulses subtly with breathing, very minimal side sway, arms barely move
Background: Solid dark blue #0D1B2A
Output: 1080x1080px, MP4, 30fps
IMPORTANT: First and last frames identical for perfect loop
Style: Calm, subtle, natural breathing
```

## 🛠️ Ferramentas Recomendadas

### Para Gerar Animações com IA:

1. **Runway ML** (Melhor qualidade)
   - https://runwayml.com/
   - Use "Gen-2" ou "Gen-3 Alpha Turbo"
   - Aceita prompts detalhados
   - Qualidade: ⭐⭐⭐⭐⭐

2. **Pika Labs** (Grátis limitado)
   - https://pika.art/
   - Bom para animações curtas
   - Qualidade: ⭐⭐⭐⭐

3. **Leonardo.ai** (Motion mode)
   - https://leonardo.ai/
   - Modo "Image to Motion"
   - Qualidade: ⭐⭐⭐⭐

4. **Animated Drawings** (Meta - Grátis)
   - https://sketch.metademolab.com/
   - Upload desenho, gera animação
   - Qualidade: ⭐⭐⭐

### Para Editar/Finalizar:

1. **EZGif** - Criar GIF de frames
   - https://ezgif.com/maker

2. **Unscreen** - Remover fundo de vídeo
   - https://www.unscreen.com/

3. **CloudConvert** - Converter formatos
   - https://cloudconvert.com/

- **Ideal**: 1080x1080px (Full HD quadrado)
- **Mínimo**: 800x800px
- **Máximo**: 1200x1200px

### Formato:
- **Preferencial**: GIF com transparência

- **Avançado**: WebM com alpha channel

### Tamanho de Arquivo:
- **GIF**: 500KB - 3MB
- **MP4**: 1MB - 5MB

- **Ideal**: 30 FPS
- **Mínimo**: 24 FPS

### Fundo:
- **Preferencial**: Transparente
- **Alternativa**: `#0D1B2A` (azul escuro)

- Se não ficou perfeito, ajuste o prompt
- Tente variações
