# Assets do Bolt ⚡

Este diretório contém todos os assets visuais do mascote Bolt.

## Estrutura de Pastas

### expressions/
Expressões do Bolt para diferentes contextos:
- `happy.png` - Treino concluído 😀
- `cool.png` - Meta batida 😎
- `excited.png` - Nova conquista 🤩
- `fire.png` - Sequência mantida 🔥
- `trophy.png` - Subiu de liga 🏆
- `sleeping.png` - Usuário inativo 😴
- `ready.png` - Pronto para treinar ⚡

### leagues/
Bolt em diferentes ligas:
- `bronze.png` - Bolt Bronze (básico)
- `silver.png` - Bolt Prata (detalhes metálicos)
- `gold.png` - Bolt Ouro (aura dourada)
- `diamond.png` - Bolt Diamante (efeitos brilhantes)
- `legendary.png` - Bolt Lendário (coroa + raio gigante)

## Especificações das Imagens

- **Formato:** PNG com fundo transparente
- **Resolução:** 512x512px (será redimensionada automaticamente)
- **Estilo:** 3D render, vibrant, amigável
- **Características do Bolt:**
  - Corpo em forma de gota azul vibrante (#007AFF)
  - Raio na cabeça (⚡)
  - Olhos grandes expressivos
  - Braços e pernas pequenos
  - Tênis de corrida modernos
  - Pulseira fitness no pulso

## Como Gerar

Use IA de imagens (Midjourney, DALL-E, Leonardo.ai) com base no `prompt.md` na raiz do projeto.

**Prompt base:**
```
Create a cute 3D character named "Bolt", a blue energetic droplet with a lightning bolt shape on top, big expressive eyes, small sporty arms and legs, wearing modern running shoes and a fitness smartwatch. Clean white background, 3D render, vibrant colors, friendly and motivational.
```

Para cada expressão, adicione:
- Happy: "smiling brightly, celebrating"
- Cool: "wearing sunglasses, confident pose"
- Excited: "jumping with joy, sparkles around"
- Fire: "surrounded by fire effect, determined"
- Trophy: "holding a golden trophy"
- Sleeping: "eyes closed, sleepy, zzz effect"
- Ready: "athletic stance, ready to run, energy aura"

Para cada liga, adicione:
- Bronze: "basic design"
- Silver: "with silver metallic details"
- Gold: "with golden aura and shine"
- Diamond: "with diamond sparkles and particles"
- Legendary: "wearing an energy crown, giant lightning bolt on back"
