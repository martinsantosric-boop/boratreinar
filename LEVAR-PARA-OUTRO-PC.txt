════════════════════════════════════════════════════════════════
    🖥️ SETUP NO OUTRO COMPUTADOR
════════════════════════════════════════════════════════════════

PASSO 1 - Instalar Flutter:
─────────────────────────────────
1. Baixe: https://docs.flutter.dev/get-started/install/windows
2. Extraia para: C:\flutter
3. Adicione ao PATH: C:\flutter\bin
4. Verifique: flutter --version


PASSO 2 - Instalar Firebase CLI:
─────────────────────────────────
npm install -g firebase-tools

Ou baixe: https://firebase.tools


PASSO 3 - Copiar Projeto:
─────────────────────────────────
Cole a pasta boratreinar em: D:\Projetos\

Ou clone do Git (se estiver no repositório)


PASSO 4 - Copiar Imagens (se não copiou projeto inteiro):
─────────────────────────────────
Do pendrive, copie pastas:
- expressions\
- leagues\

Para: D:\Projetos\boratreinar\assets\bolt\


PASSO 5 - Build e Deploy:
─────────────────────────────────
cd D:\Projetos\boratreinar
flutter pub get
flutter build web --release
firebase deploy --only hosting
